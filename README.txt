==================================================
  スマブラSP 連勝カウンター（OBS用）
==================================================

オンライン対戦の結果画面を自動で読み取って、
勝ったら +1、負けたら 0 に戻す連勝カウンターです。
配信画面に「〇連勝（最高〇）」「直近30戦 〇勝〇敗」と
直近30戦でよく負けている相手キャラ（苦手キャラ）を表示できます。


■ 導入方法の動画（約5分）
--------------------------------------------------
この手順書と同じ内容を動画で解説しています。
    https://youtu.be/IbsMmo1xUeg


■ 必要なもの
--------------------------------------------------
・Windows 10 / 11
・Windows の日本語OCR
    日本語版 Windows なら通常は最初から入っています。
    起動時に「日本語OCRが見つかりません」と出たときだけ、
    下の「日本語OCRの追加」を行ってください。
・OBS Studio 28 以降
・Python 3.10 以降
    https://www.python.org/downloads/
    ※インストール画面の最初で「Add python.exe to PATH」に
      必ずチェックを入れてください


■ はじめての設定（最初の1回だけ）
--------------------------------------------------
1. OBS の WebSocket をオンにする
   OBS のメニュー「ツール」→「WebSocket サーバー設定」
   ・「WebSocket サーバーを有効にする」にチェック
   ・「接続情報を表示」を押してパスワードを控える

2. start.bat をダブルクリック
   初回は必要な部品のダウンロードに1〜2分かかります。
   黒い画面に「OBS接続エラー」と出たら、いったん画面を閉じてください。
   （このとき config.json という設定ファイルが作られます）

3. config.json をメモ帳で開いて2か所を書き換えて保存
     "obs_password": "ここに手順1のパスワード",
     "source_name": "スイッチを映しているOBSのソース名",
   ソース名は OBS の「ソース」欄に出ている名前そのままです。
   （初期値は「映像キャプチャデバイス」）

4. もう一度 start.bat をダブルクリック
   黒い画面に「OBSに接続しました」と出れば準備完了です。


■ 配信画面に表示する
--------------------------------------------------
OBS の「ソース」→「＋」→「ブラウザ」
   URL : http://localhost:8765/
   幅  : 500   高さ : 210
   「シーンがアクティブになったときにブラウザの表示を更新」にチェック
   （表示が空のままになるのを防げます）

  ※自分のフォントで表示したい場合は、代わりに
    「テキスト(GDI+)」→「ファイルから読み取り」で
    このフォルダの streak.txt を指定してもOKです。


■ 手動で直すパネル（あると便利）
--------------------------------------------------
OBS のメニュー「ドック」→「カスタムブラウザドック」
   名前 : 連勝カウンター
   URL  : http://localhost:8765/dock
判定ミスをその場で直せます。
  ・勝ちを記録 / 負けを記録 … 見逃した試合を追加（連勝数と戦績の両方）
  ・直前を取消 … 最後の1試合を取り消して連勝数も元に戻す
  ・−1 / ＋1 / 連勝リセット … 連勝数だけ変更（戦績はそのまま）
  ・最高連勝リセット … 最高連勝数を今の連勝数から数え直す
  ・戦績クリア … 直近の戦績を全部消す


■ 表示の切り替え・連勝が途切れたときの音（任意）
--------------------------------------------------
操作パネル（ドック）の「配信画面の表示・音」で、その場でオン/オフできます。
  ・直近の戦績（〇勝〇敗） … 「直近30戦 〇勝〇敗」と勝ち負けの並び
  ・苦手キャラ … よく負けている相手キャラ
  ・連勝が途切れたら音を鳴らす … 1連勝以上から負けて0になったときに音を鳴らす

音を鳴らすには:
  1. 好きな音のファイル（mp3 / wav / ogg / m4a）を、このフォルダの
     sounds フォルダに reset.mp3 という名前で置く
     （config.json の reset_sound_file で別の名前も指定できます）
  2. OBS のブラウザソース（連勝カウンター）のプロパティで
     「OBS で音声を制御する」にチェックを入れる（音が配信に乗ります）
  3. 操作パネルで「連勝が途切れたら音を鳴らす」をオンにして、
     「音を試す」で確認
  ※音のファイルは同梱していません。配信で流してよい音を使ってください。

■ キャラアイコンを表示する（任意）
--------------------------------------------------
苦手キャラは通常キャラ名の文字で表示されます。
アイコン集を入れると「苦手 [アイコン]×3」のように表示できます。

1. 次のURLから smash_streak_icons.zip をダウンロードして展開する
     https://github.com/hochGit3232/smash-streak-counter/raw/main/smash_streak_icons.zip
2. 展開してできた smash_streak_icons フォルダの中の「assets」フォルダを、
   このフォルダ（start.bat がある場所）にコピーする
     smash_streak_counter\assets\fighters\mario.png … のようになればOK
3. start.bat を起動し直し、OBS のブラウザソースで
   「現在のページのキャッシュを更新」を押す
起動時に「キャラアイコンを読み込みました (86体)」と出れば成功です。
※アイコン画像の権利は各権利者に帰属します
  （プログラムの MIT ライセンスの対象外です）。

■ 毎回の使い方
--------------------------------------------------
★ 配信のたびに start.bat の起動が必要です。
  黒い画面を閉じるとカウンターも止まり、配信画面にも表示されなくなります。

1. start.bat をダブルクリック（黒い画面は開いたままにする）
2. OBS を起動
   ※この順番がおすすめです。OBS を先に起動していた場合は、
     下の「配信画面にカウンターが表示されない」を見てください。
3. 対戦する → 勝ち負けは自動でカウント
止めるときは黒い画面を閉じるだけです。
連勝数は保存されるので、次に起動したときも続きから数えます。


■ 自分の名前について
--------------------------------------------------
対戦相手を待っている画面（左下に ENTRY! と出る画面）で、
左下 1P 枠のネームタグを自動で読み取ります。
最初の1試合の前に、この画面を一度映してください。
うまく読めないときは config.json の "player_name" に
ネームタグを直接書いてください。


■ うまく動かないとき
--------------------------------------------------
・配信画面にカウンターが表示されない（空のまま）
    → まず start.bat が起動しているか（黒い画面が開いているか）確認。
      起動しているのに出ない場合は、OBS のブラウザソースを
      ダブルクリック →「現在のページのキャッシュを更新」を押してください。
      （start.bat より先に OBS を開くと、表示が空のまま止まることがあります。
        OBS を開き直しても直ります）

・「日本語OCRが見つかりません」と出る
    → 下の「日本語OCRの追加」を行ってください。

・黒い画面がすぐ消える / SETUP FAILED と出る
    → Python が入っていないか、PATH にチェックが入っていません。
      Python を入れ直してください。

・「OBS接続エラー」が出続ける
    → OBS が起動しているか、WebSocket がオンか、
      config.json のパスワードが合っているか確認してください。

・「No source was found」と出る
    → config.json の "source_name" が OBS のソース名と違います。

・勝ったのに増えない / 負けたのに戻らない
    → このフォルダの log.txt に判定の記録が残っています。
      config.json の "debug" を true にすると、より詳しく記録されます。

・ゲーム画面は OBS のソースいっぱいに（黒枠なしで）映してください。
・1on1 の結果画面に対応しています（4人乱闘は未対応）。


■ 日本語OCRの追加（必要な人だけ）
--------------------------------------------------
英語版 Windows や、言語設定を変更した PC では入っていないことがあります。

方法A：設定画面から
  1. 「設定」→「時刻と言語」→「言語と地域」
  2. 一覧に「日本語」が無ければ「言語の追加」で日本語を追加
     （オプション機能の「光学式文字認識」にチェック）
  3. すでに日本語がある場合は、日本語の「…」→「言語のオプション」で
     「光学式文字認識」をダウンロード

方法B：コマンドで
  スタートメニューで PowerShell を右クリック →「管理者として実行」し、
  次の1行を貼り付けて Enter
    Add-WindowsCapability -Online -Name "Language.OCR~~~ja-JP~0.0.1.0"

追加したら start.bat を起動し直してください。


■ 設定ファイル config.json の主な項目
--------------------------------------------------
  obs_password          OBS WebSocket のパスワード
  source_name           スイッチを映している OBS のソース名
  player_name           自分のネームタグ（空なら自動取得）
  text_format           streak.txt の表示形式
                        使える値: {streak}連勝数 {best}最高 {games}試合数
                                  {wins}勝ち数 {losses}負け数 {nemesis}苦手キャラ
                        例 "{streak}連勝 直近{games}戦{wins}勝{losses}敗"
  recent_count          直近何戦の勝敗を数えるか（初期値 30）
  show_recent           直近の戦績を配信画面に出すか（true / false）
  show_nemesis          苦手キャラを配信画面に出すか（true / false）
  play_reset_sound      連勝が途切れたら音を鳴らすか（true / false）
  reset_sound_file      鳴らす音のファイル（初期値 sounds/reset.mp3）
  reset_sound_volume    音量 0.0〜1.0（初期値 0.8）
  http_port             表示用のポート番号（初期値 8765）
  debug                 true で詳しい記録を log.txt に残す
