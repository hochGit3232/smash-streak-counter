# スマブラSP 連勝カウンター（OBS用）

オンライン対戦の結果画面を自動で読み取り、**勝ったら +1、負けたら 0 にリセット**する OBS 用の連勝カウンターです。

- 連勝数・最高連勝数を配信画面に表示
- 直近30戦の勝敗数・勝率・勝ち負けの並びを表示
- 直近30戦で負けた回数が多い相手キャラ（苦手キャラ）を表示
- 判定ミスを OBS のドックからワンクリックで修正
- 画面の読み取りはすべて PC 内で完結（Windows 標準の日本語OCRを使用、外部送信なし）

> 非公式のファンメイドツールです。任天堂株式会社とは関係ありません。

## ダウンロード

**[こちらのリリースページ](https://github.com/hochGit3232/smash-streak-counter/releases/latest)** から最新版の `smash_streak_counter.zip` をダウンロードして、好きな場所に展開してください。

## 必要なもの

- Windows 10 / 11 と **Windows の日本語OCR**（日本語版 Windows なら通常は入っています。[入っていない場合](#日本語ocrが入っていない場合)）
- OBS Studio 28 以降
- [Python](https://www.python.org/downloads/) 3.10 以降  
  ※インストール画面の最初で **「Add python.exe to PATH」に必ずチェック**

## はじめての設定

1. **OBS の WebSocket をオンにする**  
   OBS の「ツール」→「WebSocket サーバー設定」で「WebSocket サーバーを有効にする」にチェック。  
   「接続情報を表示」でパスワードを控える（**認証はオンのまま**にしてください）
2. **`start.bat` をダブルクリック**  
   初回は必要な部品のダウンロードに1〜2分かかります。「OBS接続エラー」と出たら一度閉じます（`config.json` が作られます）
3. **`config.json` をメモ帳で編集して保存**
   ```json
   "obs_password": "手順1のパスワード",
   "source_name": "スイッチを映しているOBSのソース名",
   ```
4. **もう一度 `start.bat` を起動**  
   「OBSに接続しました」と出れば準備完了です

## OBS に表示する

| 用途 | 追加するもの | 設定 |
| --- | --- | --- |
| 配信画面の表示 | ソース →「ブラウザ」 | URL `http://localhost:8765/`　幅 500　高さ 210 |
| 自分のフォントで表示 | ソース →「テキスト(GDI+)」 | 「ファイルから読み取り」で `streak.txt` |
| 修正用パネル | ドック →「カスタムブラウザドック」 | URL `http://localhost:8765/dock`（判定ミスの修正、最高連勝・戦績のリセット） |

ブラウザソースは「**シーンがアクティブになったときにブラウザの表示を更新**」にチェックを入れておくと、表示が空のままになるのを防げます。

`localhost` は「そのPC自身」を指すアドレスです。カウンターは同じPCの中からの接続しか受け付けません。

## 毎回の使い方

**配信のたびに `start.bat` の起動が必要です。** 黒い画面を閉じるとカウンターも止まり、配信画面にも表示されなくなります。

1. `start.bat` をダブルクリック（黒い画面は開いたままにする）
2. OBS を起動（この順番がおすすめ）
3. 対戦する → 勝ち負けは自動でカウント

連勝数と戦績は保存されるので、次に起動したときも続きから数えます。

## キャラアイコンを表示する（任意）

苦手キャラは通常キャラ名の文字で表示されます。アイコン集を入れると「苦手 [アイコン]×3」のように表示できます。

1. **[smash_streak_icons.zip](https://github.com/hochGit3232/smash-streak-counter/raw/main/smash_streak_icons.zip)** をダウンロードして展開する
2. 展開してできた `smash_streak_icons` フォルダの中の **`assets` フォルダ**を、カウンターのフォルダ（`start.bat` がある場所）にコピーする
   ```
   smash_streak_counter/
   ├─ start.bat
   ├─ fighter_icons.json       ← キャラ名とファイル名の対応表（最初から入っています）
   └─ assets/                  ← ここにコピー
      └─ fighters/
         ├─ mario.png
         ├─ captain_falcon.png
         └─ ...
   ```
3. `start.bat` を起動し直し、OBS のブラウザソースで「現在のページのキャッシュを更新」を押す

起動時に `キャラアイコンを読み込みました (86体)` と表示されれば成功です。
アイコン画像の権利は各権利者に帰属します（プログラムの MIT ライセンスの対象外です）。
## しくみ

1. OBS WebSocket で映像ソースの画面を 0.5 秒ごとに取得
2. 対戦待ちの画面（左下に `ENTRY!`）で、1P 枠のネームタグを読み取って自分の名前として保存
3. 結果画面で、金色の「1」が自分のカード側にあれば勝ち、相手側にあれば負け
   - 自分の名前が読めないとき（すぐ A を押して `READY FOR THE NEXT BATTLE` になった場合など）は、前の試合で自分がいた側で判定
4. 対戦前の VS 画面（と結果画面のカード）から相手のキャラ名を読み取り、負けた試合の相手として記録

## うまく動かないとき

- **配信画面にカウンターが表示されない（空のまま）** → `start.bat` の黒い画面が開いているか確認。開いているのに出ない場合は、ブラウザソースのプロパティで「現在のページのキャッシュを更新」を押してください（`start.bat` より先に OBS を開くと、表示が空のまま止まることがあります）
- **「日本語OCRが見つかりません」** → [下の手順](#日本語ocrが入っていない場合)で日本語OCRを追加してください
- **黒い画面がすぐ消える / `SETUP FAILED`** → Python が入っていないか、PATH にチェックが入っていません
- **「OBS接続エラー」が続く** → OBS の起動・WebSocket のオン・パスワードを確認
- **「No source was found」** → `config.json` の `source_name` が OBS のソース名と違います
- **判定ミス** → フォルダ内の `log.txt` に判定記録が残ります。`config.json` の `"debug": true` でより詳しく記録されます

### 日本語OCRが入っていない場合

英語版 Windows や、言語設定を変更した PC では入っていないことがあります。どちらかの方法で追加してください。

**方法A：設定画面から**
1. 「設定」→「時刻と言語」→「言語と地域」
2. 一覧に「日本語」が無ければ「言語の追加」で日本語を追加（オプション機能の「光学式文字認識」にチェック）
3. すでに日本語がある場合は、日本語の「…」→「言語のオプション」で「光学式文字認識」をダウンロード

**方法B：コマンドで**（スタートメニューで PowerShell を右クリック →「管理者として実行」）
```powershell
Add-WindowsCapability -Online -Name "Language.OCR~~~ja-JP~0.0.1.0"
```

追加したら start.bat を起動し直してください。

制限: 1on1 の結果画面のみ対応（4人乱闘は未対応）。ゲーム画面はソースいっぱい（黒枠なし）に映してください。

## 設定項目（config.json）

| 項目 | 説明 | 初期値 |
| --- | --- | --- |
| `obs_password` | OBS WebSocket のパスワード | 空 |
| `source_name` | スイッチを映している OBS のソース名 | `映像キャプチャデバイス` |
| `player_name` | 自分のネームタグ（空なら自動取得） | 空 |
| `text_format` | `streak.txt` の形式。`{streak}` `{best}` `{wins}` `{losses}` `{games}` `{nemesis}`（苦手キャラ）が使えます | `{streak}連勝` |
| `show_nemesis` | 配信画面に苦手キャラを表示するか | `true` |
| `recent_count` | 直近何戦の勝敗を数えるか | `30` |
| `interval_sec` | 画面を確認する間隔（秒）。PCが重いときは `1` に | `0.5` |
| `http_port` | 表示用のポート番号 | `8765` |
| `debug` | 詳しい記録を `log.txt` に残す | `false` |
